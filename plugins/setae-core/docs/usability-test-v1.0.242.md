## 進め方

1. 操作方法を先に説明しない。
2. 参加者へ各Taskの目的だけを読み上げる。
3. 質問にはすぐ答えず、参加者が何を探しているか記録する。
4. 完了条件を満たした時点で所要時間を止める。
5. 誤操作、戻り操作、発言をそのまま記録する。

## Task 1: 新しい個体を登録

依頼: 「新しく迎えた個体をSETAEへ登録してください。」

完了条件: 個体番号と種が保存され、コレクションに表示される。

## Task 2: 給餌を記録

依頼: 「いま登録した個体へ今日の給餌を記録してください。」

完了条件: 対象個体の給餌記録が保存され、記録履歴またはTodayへ反映される。

## Task 3: 脱皮前の個体を探す

依頼: 「脱皮前になっている個体を探してください。」

完了条件: 検索または絞り込みを使い、該当個体を開ける。

## Task 4: 個体ラベルを印刷

依頼: 「選んだ個体の識別票をプレビューし、印刷画面まで進んでください。」

完了条件: 実際のPhysical Label rendererを使ったプレビューを確認し、印刷flowへ進む。

## Task 5: Saved Viewを元に戻す

依頼: 「Saved Viewを削除し、すぐ元に戻してください。」

完了条件: Actionable Toastの「元に戻す」で同じ位置へ復元される。
