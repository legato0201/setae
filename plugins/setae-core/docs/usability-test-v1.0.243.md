## 進め方

1. 操作方法を先に説明しない。
2. 参加者へ各Taskの目的だけを伝える。
3. 完了までの所要時間、迷い、誤操作、戻り操作、発言を記録する。
4. 参加者が操作を中断した場合、その理由を記録する。
5. 全Taskと終了時質問が埋まるまで結果をPASSにしない。

## Task 1: 記録履歴を追加表示して戻る

依頼: 「過去の記録をさらに表示し、1件を開いてから元の位置へ戻ってください。」

完了条件: 100件ずつ追加でき、戻った後も種類、表示件数、スクロール位置が維持される。

## Task 2: 大きなベビー群を確認

依頼: 「この500匹のベビー群でA150を確認し、群全体の一括記録画面まで進んでください。」

完了条件: 100匹ずつ追加してA150を確認でき、一括処理が表示中の個体だけに限定されないと理解できる。

## Task 3: 記録中に通知を受ける

依頼: 「観察記録へ文章を入力したまま、表示された通知を確認して入力を続けてください。」

完了条件: 入力、カーソル、選択範囲、スクロール位置を失わず記録を完了できる。

## Task 4: 写真台帳から個体を探す

依頼: 「学名または個体番号で対象を検索し、主写真と個体詳細を確認してください。」

完了条件: IME入力を妨げず検索でき、写真の読込でカード位置が大きく動かない。

## Task 5: QR記録と識別票

依頼: 「QRを読み取り、対象個体の記録画面を開き、識別票の印刷画面まで進んでください。」

完了条件: カメラまたは画像読込から対象を解決し、Physical Label rendererの印刷画面へ進める。
